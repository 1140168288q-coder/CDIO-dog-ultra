# 最终实现与原材料的差异

## 入口选择

用户指定的最终来源为 `CDIO癫疯对决/红方` 和 `ASFM`。本仓库将原名 `main.py` 的文件原样放在根目录作为入口，将 `main (1).py` 原样保存为 `reference/final-variants/main_debug.py`，保留两份实现，避免按文件名猜测后覆盖其中一份。

`main_debug.py` 提供运行日志、调试监控、左右侧步进速度参数、部分硬件初始化保护与故障快速闪灯；它是独立控制器，使用时应以 `main.py` 名称部署到设备。默认根目录 `main.py` 的 `FAULT_STOP` 将 LED 关闭。两份程序均保留原内容。

## 标定工具与主程序

| 参数 | `main.py` | `motion_test.py` |
|---|---|---|
| `SERVO_OFFSETS` | `[0, 5, 12, 5, 0]` | `[0, 0, 15, 0, 0]` |
| 左侧相位速度 | 无独立倍率参数 | `LEFT_PHASE_SPEED = 1.0` |
| 右侧相位速度 | 无独立倍率参数 | `RIGHT_PHASE_SPEED = 0.97` |
| `TURN_DURATION` | 12000 ms | 10000 ms |
| `REVERSE_MS` | 6000 ms | 5000 ms |
| `RECOVERY_TURN_MS` | 12000 ms | 10000 ms |

工具通过终端菜单运行测试与编辑内存中的参数，不会自动修改主程序文件。普通幅度、时间与偏移值需手动同步；左右侧速度倍率只在标定工具和另存的调试控制器中提供，根目录主程序没有对应配置。

## 原设计文档与最终代码

原 ASFM 文件夹内保留了多个阶段的设计说明和课堂示例，因此部分内容不同：

| 主题 | 最终根目录代码的实际行为 |
|---|---|
| 扫描角度 | LD 150°、FD 85°、RD 20° |
| 扫描时机 | 仅 `FORWARD` 时更新，转向/微调/脱困期间暂停 |
| 充电期间的红色检测 | 仍然执行，目标检测可终止充电 |
| Veer 入口 | 先调用 `stop_legs()` 归中，再执行微调步态 |
| Turn / Veer 方向 | 优先朝左右距离中较大的一侧 |
| 转向角度 | 定时执行步态，没有角度反馈，不能直接将动作保证为 90° |
| Recovery 后退时间 | 6000 ms |
| Recovery 计数 | 第三次请求直接进入 Fault Stop，前两次执行脱困动作 |
| `turn_count` | Turn 完成后加一；检测到清晰路径或切换 Explore/Low Charge 时清零；Veer 不计数 |
| `recovery_count` | 切换到 Explore/Low Charge 时清零，正常前进本身不清零 |
| 超声波无回波 | 返回 100 cm，控制器按这个读数继续判定 |
| 非阻塞范围 | 状态/动作计时协作运行；脉宽读取和微秒触发存在短暂阻塞 |
| 停止含义 | 腿舵机设置中立角，PWM 不会被注销 |

`ASFM_Documentation.md` 中 Idle / Detect / Alert / Track / Lose / Capture 的示例属于早期通用状态机材料，未用于最终控制器。Word 文档、drawio、课程示例、历史 `CLAUDE`/`AGENTS` 文件均按原材料保留；当前使用说明以根目录 README 和代码为准。
